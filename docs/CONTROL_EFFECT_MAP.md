# Source control-effect evidence map

Every one of the original 282 source control sites has been individually assigned to reviewed runtime-effect evidence. Shared wrappers and repeated indexed controls use family evidence with explicit limits. This is not exhaustive state-space testing and does not close universal dataset/training exceptions or human assistive-technology acceptance.

A named occurrence is a locator aid, not proof by itself. Read the mapped assertions and reported effects. Every map row retains its scope limits. The 282-site inventory excludes native disclosure summaries, browser chrome and controls created inside third-party chart/editor libraries; those are covered by their direct renderer/editor/disclosure checks, not silently counted as source sites.
